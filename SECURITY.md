# Security

This is a static application with no backend, authentication, cookies, or user-data storage.

Report non-sensitive security problems through [GitHub issues](https://github.com/Hostlife22/gulp-starter-basic/issues). Include the affected revision, browser and reproduction steps. Do not include credentials or private data in public issues. A private reporting channel is not currently documented.

Only the current `master` version is maintained. Dependency updates must pass `npm run check`; changes affecting rendering or controls also need an explicit browser review.
